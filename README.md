## 🚀 Project 1 — Restaurant Growth Potential Modeling & Strategic Classification System

📂 **Repository:** [Restaurant-Growth-Potential-Modeling-Strategic-Classification-System](https://github.com/HariGanesh2003/Restaurant-Growth-Potential-Modeling-Strategic-Classification-System)

### 📌 Overview
A machine learning–powered system designed to model and classify the growth potential of restaurants using strategic data-driven insights. This project helps stakeholders identify high-potential restaurants and make informed expansion or investment decisions.

### 🗂️ Files
| File | Description |
|------|-------------|
| `Restaurant Growth Potential Modeling & Strategic Classification System.ipynb` | Main Jupyter Notebook with full analysis & modeling |
| `Resturant_Analysis.csv` | Dataset used for training and evaluation |
| `restaurant_dashboard.py` | Interactive Streamlit/dashboard application |
| `Restaurant_Growth_Potential_Report.pdf` | Detailed project report |
| `requirements.txt` | Python dependencies |

### 🛠️ Tech Stack
`Python` · `Pandas` · `Scikit-learn` · `Matplotlib` · `Seaborn` · `Jupyter Notebook` · `Streamlit`

### 🔑 Key Highlights
- Strategic classification of restaurants by growth potential
- Feature engineering from business and location data
- Interactive dashboard for visual analysis
- Comprehensive PDF report with insights and recommendations

## 🚀 Project 3 — Predictive Modeling and Risk Scoring for Bank Customer Churn

📂 **Repository:** [Predictive-Modeling-and-Risk-Scoring-for-Bank-Customer-Churn](https://github.com/HariGanesh2003/Predictive-Modeling-and-Risk-Scoring-for-Bank-Customer-Churn)

### 📌 Overview
A comprehensive churn prediction and risk scoring system for a European bank. The project builds machine learning models to identify customers at high risk of churning and assigns risk scores to enable proactive retention strategies.

### 🗂️ Files
| File | Description |
|------|-------------|
| `Predictive Modeling and Risk Scoring for Bank Customer Churn.ipynb` | Main analysis and modeling notebook |
| `European_Bank - European_Bank.csv` | European bank customer dataset |
| `temp.py` | Supporting Python script |
| `Predictive Modeling and Risk Scoring for Bank Customer Churn.pdf` | Full project report |
| `requirements.txt` | Python dependencies |
| `.devcontainer/` | Dev container configuration |

### 🛠️ Tech Stack
`Python` · `Pandas` · `Scikit-learn` · `XGBoost` · `Matplotlib` · `Seaborn` · `Jupyter Notebook`

### 🔑 Key Highlights
- End-to-end churn prediction pipeline on European bank data
- Risk scoring system for individual customer churn probability
- Feature importance analysis for interpretability
- Actionable retention strategy recommendations
